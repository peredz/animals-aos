# Животные с AOS — практическое задание

## Как запустить

```bash
npm install
npm run dev
```

Откроется http://localhost:5173

---

## Где работать

Все изменения делать в файле `src/App.jsx`.

---

## Задание 1. Добавь анимацию появления

Каждому животному нужно добавить эффект появления при скролле:

- Овца — вылетает слева
- Корова — вылетает справа
- Свинья — вылетает снизу
- Лягушка — вылетает сверху

Для этого добавь атрибут `data-aos` в карточку животного:

```jsx
<div className="animal-card" data-aos="fade-left">
```

Возможные значения:
- `fade-left` — вылет слева
- `fade-right` — вылет справа
- `fade-up` — вылет снизу
- `fade-down` — вылет сверху

---

## Задание 2. Добавь задержку

Добавь задержку 200мс каждому животному, чтобы они появлялись по очереди:

```jsx
data-aos-delay="200"
```

Первая карточка — 0мс, вторая — 200мс, третья — 400мс, четвертая — 600мс.
